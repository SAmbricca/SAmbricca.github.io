AI Log-Analysis & Root-Cause Agent

RAG · MCP · Vector Search · Evaluation Harness

A retrieval-augmented agent that ingests AWS CloudWatch logs, groups them into incidents, embeds them into a vector store, and retrieves similar past failures to draft root-cause analyses. Live CloudWatch queries are exposed to the agent as tools through a custom MCP server, so it reasons over real-time data instead of static context.

  • Incident detection & grouping — normalizes volatile data (timestamps, UUIDs, IPs) and clusters related errors.
  • Local vector embeddings — sentence-transformers (MiniLM) for semantic search with zero API cost.
  • Custom MCP server — 4 agent tools: query_logs, index_logs, search_similar_incidents, draft_rca.
  • Swappable RCA backend — free offline templates or Claude API, opt-in via env key.
  • Evaluation harness — labeled dataset with hit@k & MRR to catch retrieval regressions and flag hallucinated root causes.
